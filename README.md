# 🌱 FarmConnect – Smart Farming Mobile App UI/UX Design

## 📌 Overview

FarmConnect is a mobile application designed to assist farmers with crop management, disease detection, weather updates, market prices, and AI-powered farming assistance.

The goal of this project is to provide a simple and user-friendly platform that helps farmers make informed decisions and improve agricultural productivity.

---

## 🎯 Problem Statement

Small-scale farmers often struggle to access:

- Crop disease diagnosis
- Accurate weather forecasts
- Market price updates
- Farming guidance and recommendations

FarmConnect aims to solve these challenges through a single mobile application.

---
